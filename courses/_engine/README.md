# courses/_engine

Plantilla común de todas las páginas de curso generadas por
[pdf2course](https://github.com/samuel-cerezo/pdf2course). **No edites estos ficheros aquí**:
se sobrescriben en cada sincronización. El original está en `website/_engine/` del repo pdf2course.

Cada curso tiene una página mínima en `courses/<slug>/index.html` que carga `engine.js` y
`engine.css` con su slug y la URL de la API.
