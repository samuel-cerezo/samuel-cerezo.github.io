# Caratteri auto-ospitati

Font variabili originali, distribuiti con la licenza SIL Open Font License allegata.

- Open Sans: https://github.com/google/fonts/tree/main/ofl/opensans
- Noto Sans: https://github.com/google/fonts/tree/main/ofl/notosans
- Source Sans 3: https://github.com/google/fonts/tree/main/ofl/sourcesans3

Il corso usa Source Sans 3 per impostazione iniziale. La pagina #caratteri permette di provare le tre varianti; la scelta resta sul dispositivo del visitatore.

Per il web i font sono sottoinsiemi WOFF2 latini. Il derivato di Source Sans 3 usa il nome interno Course Sans 3 per rispettare il Reserved Font Name; il disegno deriva da Source Sans 3.
